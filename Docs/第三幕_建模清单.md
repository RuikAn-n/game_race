# 入谱 · 第三幕「守城」建模与资产清单 v1

> 用途：直接给建模 / 场景 / 动画 / UI 派单，也可作为验收表。
> 范围：**第三幕 1560 夏·八波守城** 的战场、人物、道具、动画、VFX、贴图、UI。
> 依据：`第三幕_守城_策划案_v1.md`、`Docs/act3_enemies.md`、`Docs/act2_assets.md`、`Docs/ming_buildings_civic.md`、`Docs/map_yongchang.md`、`Docs/act45_assets.md`。
> 更新时间：2026-11-27。

---

## 0. 先说结论

第三幕**不缺敌人和 Boss**。`act3_enemies.md` 里已经完成：

- 4 种敌人 × 2 变体 = **8 个敌人模型**；
- 2 个 Boss × 3 阶段 = **2 套 Boss 模型 + 6 把武器**；
- 云梯、冲车、火船、火炮、炮位、水轮、闸门、拒马、火油、水桶、担架、城墙破口 = **12 组攻守城道具**；
- **39 个战斗动作**（刀/弓/火罐/盾 + 赤焰/鬼倭）；
- **27 个 VFX**（血/火/水/烟/破片/箭矢/蒸汽等）；
- 明代环海楼、水门闸套件、城门楼、祖祠、粮仓、城墙、瓮城、码头、水田、盐场；
- 王砚 1560、王沛、王叔杲、王德、族老、匠人、民夫、义师、妇人、孩童。

**不要重做这些。** 第三幕真正缺的是：

1. **玩家自己的战斗套件**（枪、动作、受击/处决/死亡）——现在没有；
2. **战场状态件**（烧焦码头、闸室、街垒、粮仓破门、瓮城防守、战场残骸）；
3. **社会 Boss 的道具**（愧顽簿、名墙、粮袋/粮斗/粮车）；
4. **指挥/信号/取水/修墙的小道具**（旗、鼓、火盆、箭捆、石堆、油坛、拒马、铁链、小船）；
5. **百姓/伤兵/尸体/阿贵**；
6. **UI + 贴图**（四状态、军议、指挥、整备、记谱、Boss 条、旗面/匾/名签/谱页的字）；
7. **动画事件**（现有 FBX 里没有 AttackHit/PhaseChange/Stagger/Death）。

**最小可玩批次（P0）共 39 个条目（含变体与小件）；先做其中最关键的 24 个，就能把 W1 + 巡城 + 军议 + 战后记谱跑起来。**

## 1. 统一规格

| 项 | 规格 |
|---|---|
| 单位 | 1 Unity unit = 1 m |
| 朝向 | 模型正面 +Z，脚底 y=0，原点在脚底/底面中心 |
| 人物身高 | 王砚 1.75；王叔杲 1.72；族老 1.66—1.73；阿贵 1.68；义师 1.70—1.78；百姓 1.18—1.70 |

| 材质 | 与现有 Whitebox 一致：低饱和纯色 + 少量 1K/2K 贴图；PBR/URP |
| 贴图 | 人物 1K；建筑 2K 图集；文字面 0..1 UV，不把字烘进网格 |
| 骨骼 | Humanoid，22 骨，沿用 `CH_WangYan_1941` / 敌人骨架 |
| 动画 | 24 fps；片段名即 Animator 状态名；循环片段带 `Loop` |
