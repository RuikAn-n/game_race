对白与盘问全部按 `空格` 推进；关键台词有中文 TTS 音频。

## 第一幕操作

1. 打开 `Assets/Scenes/Act1_1941.unity`，Play。
2. 开场旁白 → 族老告知父亲失踪 → 与族亲交谈（冷遇/亲善）。
3. 去父亲灵位上香，族老带王砚认王沛、王叔杲牌位。
4. 日本军官威胁交谱，王秉之拒绝。
5. 祠堂供桌前按住 `E` 拼合残谱。
6. 内院依次与交谱派、烧谱派、藏谱派交谈；每句对白按 `空格` 推进。
7. 三派说完后，三拨人聚拢争吵，族长站出来结束春祭。
8. 出院子后才触发街景旁白；日军在街上欺压小贩，军官拔刀盘问，王砚解释“我是王家的人”。
9. 沿民国街市走到环海楼。
10. 斜倒的旗杆前按住 `E`。
11. 看穿越黑屏与第一幕结束。
