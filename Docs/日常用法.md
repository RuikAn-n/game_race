# 日常用法（B：建模 / 动画 → 团结 → Windows 测试）

环境配置和原理见仓库根目录的 `README.md`。本文只讲每天要做的事。所有命令都在仓库根目录 `game_race/` 下执行。

## 0. 开工

```bash
git pull                       # 先同步 A 的改动
Tools/mac/check_env.sh         # 环境异常时再跑
```

## 1. 新建一个模型

```bash
Tools/mac/new_asset.sh Characters NPC_WangYan     # 分类 + 资产名，会自动用 Blender 打开
```

| 分类 | 前缀 | 三角面上限 |
|---|---|---|
| Characters | `NPC_` / `CH_` | 8k |
| Enemies | `EN_` | 8k |
| Bosses | `BOSS_` | 15k |
| Buildings | `BLD_` | 20k |
| Props | `PROP_` | 3k |
| Environments | `ENV_` | 40k |

建模规则：

- 正面朝 **-Y**，也就是参考箭头 `REF_FRONT_-Y` 指的方向。
- 脚底落在 z=0。
- 1 格 = 1 米。参考人身高 1.75m。
- `_REF` 集合里的参考物不会被导出，不用删。
- 完成后按 **Ctrl+A** 应用旋转和缩放。

## 2. 导出到团结

在 Blender 的 3D 视图按 **N**，打开「入谱」页签：

1. 点 **检查**。红色是错误，必须修复；黄色是警告，建议修复。
2. 点 **导出到团结工程**，FBX 会写到 `Project_rupu/Assets/Art/<分类>/<资产名>/`。

切回团结编辑器后会自动导入，导入设置已由规则套好。

> 首次使用要装插件：Blender > 偏好设置 > 插件 > 从磁盘安装 > `Tools/blender/rupu_pipeline.py`

批量重导所有 .blend：`Tools/mac/blender_export_all.sh`

## 3. 角色绑定与动画（Mixamo 流程）

1. 导出不带骨架的角色 FBX。
2. 上传到 mixamo.com 自动绑定，下载格式选 **FBX for Unity**，勾选 With Skin。
3. 放到 `Project_rupu/Assets/Art/Characters/<名>/<名>.fbx`，导入器会自动设为 **Humanoid**。
4. 动画下载时选 Without Skin，命名为 `<名>@Walk.fbx`、`<名>@Idle.fbx` 等。文件名含 idle / walk / run / loop 的会自动循环播放。
5. 人形动画所有 NPC、敌人、Boss 通用，同一个动作只需做一次。
6. 攻击类动画要加动画事件：`AttackHit` `PhaseChange` `Stagger` `Death` `Footstep`。

## 4. 在团结里看效果

- 菜单 **入谱 > 创建美术测试场景**：`Assets/Art` 下所有模型会排成一排，旁边有 1m 立方体和 1.75m 参考人用来比对。
- 点 Play：
  - 第三人称：WASD 移动，Shift 奔跑，鼠标转视角，滚轮调距离。
  - 按 **Tab** 切到俯视（策略视角）：WASD 平移，Q/E 旋转，滚轮缩放。
- 检查四项：比例对不对、朝向是不是 +Z、有没有粉色材质、pivot 是否在脚底。

## 5. 出 Windows 包并在虚拟机测试

**编辑器开着时**：菜单 **入谱 > 构建 Windows x64 (Development)**。

**编辑器关着时**：

```bash
Tools/mac/build_win.sh             # 开发版
Tools/mac/build_win.sh --release   # 发布版
```

两种方式都输出到 `Builds/Windows/Rupu.exe`。

在虚拟机里运行：

1. 在 Fusion 打开 Win11 虚拟机。
2. Mac 上运行 `Tools/mac/serve_build.sh`。它会把构建打包，只在 VMware 虚拟网卡上开下载服务，局域网访问不到。
3. 在 VM 里按 **Win+R**，粘贴脚本打印出来的那行命令，回车：

   ```text
   powershell -ExecutionPolicy Bypass -c "iex (iwr http://192.168.214.1:8624/get_and_run.ps1 -UseBasicParsing).Content"
   ```

   它会下载最新构建，解压到 `%LOCALAPPDATA%\RupuTest`，然后启动游戏。以后每次重新构建，再执行一次这行命令就行。
   这台 VM 加密了，Fusion 设置里没有「共享」选项，所以用这种方式代替共享文件夹。
4. 出问题时查看日志：`%USERPROFILE%\AppData\LocalLow\RupuTeam\入谱\Player.log`

> 虚拟机是 ARM 版 Win11，x64 游戏要经过转译运行，只能用来测"能不能跑、画面对不对"。帧率要在 A 的 Windows 实机上测。

## 6. 提交

```bash
git checkout -b b/content        # 第一次；之后用 git checkout b/content
git add -A
git commit -m "B: NPC_WangYan 模型 + idle/walk"
git push -u origin b/content     # 每天合入 main
```

- .blend / .fbx / .png / .wav 等二进制文件自动走 Git LFS。
- 新增资产时，在 `Data/asset_manifest.csv` 加一行。
- 用了第三方素材，在 `Docs/licenses.md` 登记来源和许可证。

## 常见问题

| 现象 | 处理 |
|---|---|
| `build_win.sh` 报工程被锁 | 编辑器开着这个工程，改用菜单构建 |
| 构建时报许可证错误 | 打开 Tuanjie Cowork，在「项目」页右上角的许可证图标里点刷新 |
| 模型在团结里躺倒或朝后 | Blender 里没按 Ctrl+A 应用旋转，或者正面不是朝 -Y |
| 模型是粉色 | 材质用了 URP 不支持的着色器，在团结里改为 URP/Lit |
| 导出时报"团结工程还不存在" | 没有 `Project_rupu/Assets`，先执行 `git pull` |
| 修改了 `Tools/unity_seed/` 里的脚本 | 运行 `Tools/mac/seed_unity_project.sh` 同步到工程 |
