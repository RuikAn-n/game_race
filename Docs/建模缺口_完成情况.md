## 新增生成模块（Tools/blender/）

所有模块都由 `build_yongchang.py` 统一驱动，每幕一个文件：`rupu_act1p1.py`、`rupu_ming_house.py`、`rupu_ming_civic.py`、`rupu_act2.py`、`rupu_enemy.py`、`rupu_act45.py`。`rupu_char.py` 新增三个扩展钩子：`HAIR_HOOKS`、`EXTRA_HOOKS`、`GESTURE_HOOKS`，这样其他模块加头饰、配件、动作时都不用改 `rupu_char.py`。

```bash
# 只重建某些资产（已存在的 .blend 默认跳过，--force 覆盖）
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P Tools/blender/build_yongchang.py -- --only BOSS_Guiwo,PROP_SiegeLadder --force
```
