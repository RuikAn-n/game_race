# 第二幕《筑堡》策划对照与建模缺口清单

> 对照文件：[入谱_第二幕_筑堡_策划案_v1.md](D:\太平日月\太平守望2\入谱_第二幕_筑堡_策划案_v1.md)
>
> 当前场景：`Assets/第二幕/Scenes/Act2_1560.unity`
>
> 当前状态：可玩原型，不是完整 12—15 分钟成片

---

## 0. 先说结论

现在第二幕已经有的是一条**能走通的主流程骨架**：

```text
祠堂开工
→ 沙盘三决策
→ 盐场
→ 族约
→ 王宅
→ 北门殉难
→ 战后名录
→ 结算
```

但对照策划案，当前仍缺三类东西：

1. **玩法深度没到**：五天工地日、资源系统、信任值、决策后的完整建造过程都没有。
2. **建模和场景还是“资产摆场”**：建筑用了明代模型，但城市密度、道路、城墙、工地、室内细节没有形成完整城镇。
3. **表现层不够**：沙盘手部动作、墙线生长、合龙、凿碑、记名墨迹、战斗动作都没有真正接上。

一句话：

> **现在是“第二幕的可玩 demo”，不是“第二幕的完整关卡”。**

## 9. 建议补做顺序

### 第一步：把“城”做对

1. 自动检查建筑包围盒，禁止街区重叠
2. 主街/横街/巷道连通，建筑退线一致
3. 北门、东门、西门、南墙形成完整闭合
4. 王宅固定在城墙外，城内/城外有清楚道路
5. 盐场固定在城内东北，不再压路

### 第二步：把“沙盘”做完整

1. B 案 `PROP_Sand_*` 重生成
2. 三固定机位
3. 墙线/敌台/水门/王宅四个热区
4. 拉线/插旗/推闸手部动作
5. 墙线隆起、水门水流、王宅木片移动
6. 沙盘皮肤 1560/1941/1945

### 第三步：把“五天”做出来

1. 5 天循环
2. 巡工/记名/筹银/劝人
3. 银/石/木/工/粮
4. 工期和永远差一件
5. 王沛/王叔杲信任值

### 第四步：把“选择结果”做出来

1. 圈宅 → 城墙围合
2. 墙线 → 世界城墙段出现
3. 敌台 → 世界敌台出现
4. 水门 → 世界水门开/闭
5. 殉难 → 1v3/合龙/护民三个小段
6. 名录 → 纸面、墨迹、人数、结局写回

### 第五步：把“建模细节”补上

1. 旗面/灯面/匾/印文/页槽字
2. 工地脚手架/石料/灰浆/夯土
3. 族约碑碑文和凿痕
4. 名录纸张和墨迹
5. LOD
6. 第二幕环境音

## 10. 验收标准（按策划案 5 问）

1. 12—15 分钟能不能走完？
   - **现在不能**，流程明显短于策划案。
2. 玩家能不能在八波里指认“这是我当初选的墙线”？
   - **只能看到本地墙段，尚未写回八波。**
3. 名录有没有人真的坐下来记完 30 个名字？
   - **没有 30 个，也没有纸面过程。**
4. 殉难结果固定，玩家是否仍然觉得“我做了选择”？
   - **现在只有选择，没有三段不同场面。**
5. 王沛和王叔杲，玩家能不能一句话说出区别？
   - **台词有，但动作、信任和代价没有落地。**

## 12. 一句话总结

> **第二幕现在有骨架、有资产、有决策，但还没有“五天工地”“手上的沙盘”“墙真的合龙”“王沛真的出战”“名字真的被写下来”。**
>
> 下一步不是继续加房子，而是把**沙盘动作、五天循环、城墙合龙、殉难三段、名录纸面**这五个核心体验做出来。
